プロジェクトセットアップ手順 (Windows)
====================================

このプロジェクトは、PDF/DOCX/XLS/XLSX からテキストを抽出し、クレンジング後に
DSL スクリプトで CSV を生成します。

前提条件
--------
- Windows 環境
- Python 3.10 以上 (3.13 で確認)
- Git は任意 (cloneする場合のみ)
- `results/` を作成できる十分な空き容量

1) コード取得
-------------
GitHub から clone する場合:
git clone <repo-url>
cd PDFextract

ZIP の場合:
ZIPを解凍し、プロジェクトルートで PowerShell を開いてください。

2) 仮想環境の作成と有効化
------------------------
python -m venv .venv
.\.venv\Scripts\Activate

3) 依存ライブラリのインストール
------------------------------
python -m pip install --upgrade pip
pip install -r requirements.txt

任意チェック:
python -c "import fitz, pandas, yaml; print('ok')"

4) 入力ファイルの準備
--------------------
- PDF/DOCX/XLS/XLSX を `input/` 配下に配置
- サブフォルダ構成は出力側にも引き継がれます

5) 抽出
-------
- 通常抽出:
  python text_extractor.py
  出力先: `results/output1/`
  ログ: `results/extraction_log.csv`

- hybrid抽出:
  python hybrid_extraction.py
  出力先: `results/test1/`
  ログ: `results/test1/log.csv`

6) クレンジング
---------------
- 通常系:
  python text_cleaner.py --input-dir results/output1 --output-dir results/output2
- hybrid系:
  python text_cleaner.py --input-dir results/test1 --output-dir results/test2

7) ポストクレンジング
--------------------
- 通常系:
  python post_clean_output3.py --input-dir results/output2 --output-dir results/output3
- hybrid系:
  python post_clean_output3.py --input-dir results/test2 --output-dir results/test3

8) マージ処理 (対象地域のみ)
--------------------------
- 86:
  python merge_86_texts.py --input_dir "results/test3/【86】近畿" --output_dir "results/test4/【86】近畿"
- 89:
  python merge_89_texts.py --input_dir "results/test3/【89】九州" --output_dir "results/test4/【89】九州"

9) DSL 抽出
-----------
地域ごとに以下を実行:

python dsl_engine.py --script 82_script.dsl --input_dir "results/output3/【82】東北" --outdir "results/csv/【82】東北"
python dsl_engine.py --script 83_script.dsl --input_dir "results/output3/【83】関東" --outdir "results/csv/【83】関東"
python dsl_engine.py --script 84_script.dsl --input_dir "results/output3/【84】北陸" --outdir "results/csv/【84】北陸"
python dsl_engine.py --script 85_script.dsl --input_dir "results/test3/【85】中部" --outdir "results/csv/【85】中部"
python dsl_engine.py --script 86_script.dsl --input_dir "results/test4/【86】近畿" --outdir "results/csv/【86】近畿"
python dsl_engine.py --script 87_script.dsl --input_dir "results/output3/【87】中国" --outdir "results/csv/【87】中国"
python dsl_engine.py --script 88_script.dsl --input_dir "results/output3/【88】四国" --outdir "results/csv/【88】四国"
python dsl_engine.py --script 89_script.dsl --input_dir "results/test4/【89】九州" --outdir "results/csv/【89】九州"
python dsl_engine.py --script 90_script.dsl --input_dir "results/output3/【90】沖縄" --outdir "results/csv/【90】沖縄"

python dsl_engine.py --script 810_script.dsl --input_dir "results/test3/【810】" --outdir "results/csv/【810】"
python dsl_engine.py --script 811_script.dsl --input_dir "results/test3/【811】" --outdir "results/csv/【811】"
python dsl_engine.py --script 812_script.dsl --input_dir "results/test3/【812】" --outdir "results/csv/【812】"
python dsl_engine.py --script 813_script.dsl --input_dir "results/test3/【813】" --outdir "results/csv/【813】"
python dsl_engine.py --script 814_script.dsl --input_dir "results/test3/【814】" --outdir "results/csv/【814】"
python dsl_engine.py --script 815_script.dsl --input_dir "results/test3/【815】" --outdir "results/csv/【815】"
python dsl_engine.py --script 816_script.dsl --input_dir "results/test3/【816】" --outdir "results/csv/【816】"
python dsl_engine.py --script 817_script.dsl --input_dir "results/test3/【817】" --outdir "results/csv/【817】"
python dsl_engine.py --script 818_script.dsl --input_dir "results/test3/【818】" --outdir "results/csv/【818】"
python dsl_engine.py --script 819_script.dsl --input_dir "results/test3/【819】" --outdir "results/csv/【819】"

補足:
- `--outdir` は存在しない場合に自動作成されます
- すべて一括で実行する場合は `.\run_pipeline.ps1` が推奨です

10) 出力場所
-----------
- 抽出テキスト: `results/output1` / `results/test1`
- クレンジング後: `results/output2` / `results/test2`
- ポストクレンジング後: `results/output3` / `results/test3`
- マージ後: `results/test4` (86,89)
- CSV: `results/csv/<地域>`


ENGLISH

PROJECT SETUP AND RUN GUIDE (Windows)
====================================

This project extracts text from PDF/DOCX/XLS/XLSX files, cleans it, then runs
DSL scripts to generate CSV outputs.

Prerequisites
-------------
- Windows with Python 3.10+ (tested with 3.13)
- Git (optional, only needed if you clone)
- Enough disk space under `results/`

1) Get the code
---------------
If cloning from GitHub:
git clone <repo-url>
cd PDFextract

If using ZIP:
Unzip and open PowerShell in the project root.

2) Create and activate a virtual environment
--------------------------------------------
python -m venv .venv
.\.venv\Scripts\Activate

3) Install dependencies
-----------------------
python -m pip install --upgrade pip
pip install -r requirements.txt

Optional sanity check:
python -c "import fitz, pandas, yaml; print('ok')"

4) Prepare input files
----------------------
- Put PDF/DOCX/XLS/XLSX files under `input/`
- Subfolders are supported and preserved

5) Run extraction
-----------------
- Standard extractor:
  python text_extractor.py
  Output: `results/output1/`
  Log: `results/extraction_log.csv`

- Hybrid extractor:
  python hybrid_extraction.py
  Output: `results/test1/`
  Log: `results/test1/log.csv`

6) Clean extracted text
-----------------------
python text_cleaner.py --input-dir results/output1 --output-dir results/output2
python text_cleaner.py --input-dir results/test1 --output-dir results/test2

7) Post-clean
-------------
python post_clean_output3.py --input-dir results/output2 --output-dir results/output3
python post_clean_output3.py --input-dir results/test2 --output-dir results/test3

8) Merge (required regions)
---------------------------
python merge_86_texts.py --input_dir "results/test3/【86】近畿" --output_dir "results/test4/【86】近畿"
python merge_89_texts.py --input_dir "results/test3/【89】九州" --output_dir "results/test4/【89】九州"

9) Run DSL extraction
---------------------
Use the same region commands listed in the Japanese section above.
Important updates:
- `85_script.dsl` uses `results/test3/【85】中部`
- `818_script.dsl` is included

10) Where outputs go
--------------------
- Extracted text: `results/output1` / `results/test1`
- Cleaned text: `results/output2` / `results/test2`
- Post-cleaned text: `results/output3` / `results/test3`
- Merged text: `results/test4` (86,89)
- CSV outputs: `results/csv/<region>`


final order :

1) python -m venv .venv
2) .\.venv\Scripts\Activate
3) python -m pip install --upgrade pip
4) pip install -r requirements.txt
5) python text_extractor.py
6) python hybrid_extraction.py
7) python text_cleaner.py --input-dir results/output1 --output-dir results/output2
8) python text_cleaner.py --input-dir results/test1 --output-dir results/test2
9) python post_clean_output3.py --input-dir results/output2 --output-dir results/output3
10) python post_clean_output3.py --input-dir results/test2 --output-dir results/test3
11) python merge_86_texts.py --input_dir "results/test3/【86】近畿" --output_dir "results/test4/【86】近畿"
12) python merge_89_texts.py --input_dir "results/test3/【89】九州" --output_dir "results/test4/【89】九州"
13) Run region-wise `dsl_engine.py` commands from section 9
14) (Recommended alternative) .\run_pipeline.ps1
