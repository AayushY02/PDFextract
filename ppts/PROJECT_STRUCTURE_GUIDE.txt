
======================================================================
プロジェクト構成ガイド
======================================================================

1) プロジェクト目的
本プロジェクトは、入札関連文書（PDF、DOCX、XLS/XLSX）からテキストを抽出し、段階的に整形した後、地域別DSLルールで必要項目を抽出し、地域単位のCSV/Excel要約を出力する構成です。

主な到達点:
- `input/` に元データを配置
- パイプラインを実行
- `results/csv/` に地域別要約を出力

現在の出力方針:
- `dsl_engine.py` はフォルダ実行時、地域単位の `*_levels_summary.csv` / `*_levels_summary.xlsx` を主出力とする設定です。
- 案件別CSV/Excelおよびall_texts_summary系ロジックは将来再有効化可能な形でコード内に保持されています。
- `merge_region_summaries.py` はデフォルトでlevels系結合を生成する設定です。


2) トップレベル構成
`code zip` 直下の現状:
- フォルダ: 3
- ファイル: 46

直下フォルダ:
- `input/`
- `results/`

直下の役割:
- `input/`: 元データ
- `results/`: 中間成果物と最終成果物
- 直下ファイル群: 実行スクリプト、DSLルール、起動スクリプト、導入/運用文書


3) 実行フロー
標準フル実行（`run_pipeline.ps1`）:
1. `text_extractor.py` -> `results/output1`
2. `hybrid_extraction.py` -> `results/test1`
3. `text_cleaner.py`（`output1 -> output2`）
4. `text_cleaner.py`（`test1 -> test2`）
5. `post_clean_output3.py`（`output2 -> output3`）
6. `post_clean_output3.py`（`test2 -> test3`）
7. `merge_86_texts.py`（`test3/【86】近畿 -> test4/【86】近畿`）
8. `merge_89_texts.py`（`test3/【89】九州 -> test4/【89】九州`）
9. 地域DSL実行（`dsl_engine.py`）-> `results/csv/<地域フォルダ>`

地域のみ再実行（`run_regions_pipeline.ps1`）:
- 上記9のみ実行
- `results/output3`、`results/test3`、`results/test4` が事前に必要

7) 出力命名規則
ステージ出力:
- 案件名はステージ間で基本的に継承
- ステージ判定はフォルダ名（`output1/2/3`, `test1/2/3/4`）

地域要約出力:
- `<地域>_levels_summary.csv`
- `<地域>_levels_summary.xlsx`

地域横断結合出力:
- `merged_levels_summary_<group>.csv`
- `merged_levels_summary_<group>.xlsx`


8) 運用確認チェックリスト
地域要約が不足・欠落している場合:
1. `input/` に対象地域フォルダが存在するか確認
2. 対応する中間ステージ出力が存在するか確認
3. 対応するDSLファイル（`<region>_script.dsl`）が存在するか確認
4. 必要に応じてフル実行または地域のみ再実行を実施
