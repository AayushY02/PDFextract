Windows setup (Python 3.10+; tested with Python 3.13)
------------------------------------------------------

1) Create and activate a virtual environment (PowerShell, project root)
- `python -m venv .venv`
- `.\.venv\Scripts\Activate`

2) Install dependencies
- Upgrade pip: `python -m pip install --upgrade pip`
- Install packages: `pip install -r requirements.txt`
  - Includes pandas, pdfminer.six, PyYAML, PyMuPDF, python-docx, openpyxl, xlrd, pywin32.

3) Extract text
- `python text_extractor.py`  (writes to `results/output1`)
- `python hybrid_extraction.py` (writes to `results/test1`)

4) Clean extracted text
- Others: `python text_cleaner.py --input-dir results/output1 --output-dir results/output2`
- 810-819 and hybrid track: `python text_cleaner.py --input-dir results/test1 --output-dir results/test2`

5) Post-clean text
- Others: `python post_clean_output3.py --input-dir results/output2 --output-dir results/output3`
- 810-819 and hybrid track: `python post_clean_output3.py --input-dir results/test2 --output-dir results/test3`

6) Merge required regions (run from project root)
- 86 merge: `python merge_86_texts.py --input_dir "results/test3/【86】近畿" --output_dir "results/test4/【86】近畿"`
- 89 merge: `python merge_89_texts.py --input_dir "results/test3/【89】九州" --output_dir "results/test4/【89】九州"`
