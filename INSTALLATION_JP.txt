Windows セットアップ手順 (Python 3.10以上、3.13で確認)
--------------------------------------------------------

1) 仮想環境を作成して有効化 (PowerShell、プロジェクトルート)
- `python -m venv .venv`
- `.\.venv\Scripts\Activate`

2) 依存ライブラリをインストール
- pip更新: `python -m pip install --upgrade pip`
- 依存導入: `pip install -r requirements.txt`
  - pandas, pdfminer.six, PyYAML, PyMuPDF, python-docx, openpyxl, xlrd, pywin32 を含む

3) 抽出
- `python text_extractor.py`  (`results/output1`へ出力)
- `python hybrid_extraction.py` (`results/test1`へ出力)

4) クリーニング
- 通常系: `python text_cleaner.py --input-dir results/output1 --output-dir results/output2`
- 810-819 と hybrid系: `python text_cleaner.py --input-dir results/test1 --output-dir results/test2`

5) ポストクリーニング
- 通常系: `python post_clean_output3.py --input-dir results/output2 --output-dir results/output3`
- 810-819 と hybrid系: `python post_clean_output3.py --input-dir results/test2 --output-dir results/test3`

6) マージが必要な地域
- 86マージ: `python merge_86_texts.py --input_dir "results/test3/【86】近畿" --output_dir "results/test4/【86】近畿"`
- 89マージ: `python merge_89_texts.py --input_dir "results/test3/【89】九州" --output_dir "results/test4/【89】九州"`
